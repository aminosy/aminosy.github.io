## 第一阶段：Python + 工程基础（4 周）

目标：能独立写 Python 脚本、用 Git 管理代码、用 Docker 跑通容器。不需要碰任何 AI 课程，基础不牢后面全是空中楼阁。

### 第 1 周：Python 语法筑基

- **上午**：环境安装（VS Code + Python 3.10+）→ 变量与数据类型 → 条件语句 → `for/while` 循环
- **下午**：手写练习（如判断闰年、打印九九乘法表）；每天抽 30 分钟熟悉 Linux 基础命令（`ls`、`cd`、`mkdir`、`cat`、`grep`）

### 第 2 周：核心数据结构与函数

- **上午**：列表、元组、字典、集合的操作 → 函数定义与参数传递
- **下午**：用列表/字典写一个简单的通讯录管理程序（增删改查）；开始 Git 基础（`init`、`add`、`commit`、`push`），把每天的代码提交到 GitHub

### 第 3 周：文件操作与异常处理

- **上午**：文件读写（`open`、`read`、`write`）→ `try/except` 异常处理
- **下午**：完成一个文本文件处理小工具（如读取日志文件并统计关键词频率）；学习 Git 分支操作；了解 Docker 基本概念（镜像与容器），尝试运行一个 `hello-world` 容器

### 第 4 周：Docker 实操 + 综合项目

- **上午**：模块与标准库（`os`、`json`）→ 简单面向对象（类与对象的基础概念）
- **下午**：写一个 CLI（命令行）待办事项工具，用 Git 管理代码，最后为它写一个 Dockerfile 并成功构建运行

## 第二阶段：CME 295（6-8 周，主修核心）

CME 295 是整条路线的“中枢课程”，由 Amidi 兄弟主讲，内容覆盖主修方向需要的全部关键概念：

- **Transformer 核心**：自注意力、架构变体、Flash Attention 等优化技术
- **LLM 操作**：Prompting、SFT、LoRA 微调、量化、蒸馏
- **应用层**：RAG、Agent、LLM-as-a-Judge、推理模型（DeepSeek-R1 的训练与测试时扩展）

这门课的定位非常精准：**它不是教你从零训练模型，而是教你理解模型、用好模型、在上面构建应用**。这正是 AI 构建者的核心能力。课程网站是 `cme295.stanford.edu`，有 VIP Cheatsheet 和配套教材《Super Study Guide: Transformers & Large Language Models》可以参考。

**学习方式**：以理解概念和跑通代码为主，不要追求数学推导的完整掌握。重点是把 RAG 和 Agent 的基本模式吃透。

## 第三阶段：CS329Z + 实战项目（6-8 周）

CS329Z 是主修方向的“终极对口课”。斯坦福 2026 年秋季新开，专门讲 AI Agent 的工程化构建。课程大纲把 Agent 系统拆成五个工程层，每一层都有明确的交付物：

| 层级 | 内容 | 你要产出的东西 |
|---|---|---|
| **任务与上下文** | 问题拆解、模型选择、RAG | 可量化的任务契约 + 检索基线 |
| **行动** | Function Calling、MCP、沙箱、重试 | 类型化工具 + 权限边界 |
| **编排** | DSPy、LangGraph、记忆、多 Agent | 显式状态 + 交接契约 |
| **改进** | 追踪、演示、数据选择、优化 | 版本化的 trace 集 + 优化决策 |
| **保障** | 评测设计、评分器、安全、可观测性 | 发布门禁 + 失败分类 |

课程要求学生**先动手构建，再抽象理解**。第一个作业是搭一个科学问答 Agent（检索 + 工具调用 + Agent 循环），然后用 DSPy 重写关键部分。第二个作业反过来：给你一个 Agent，让你构建评测体系。

**这门课和 CME 295 的关系**：CME 295 教你“组件是什么”，CS329Z 教你“怎么把它们组装成生产系统”。学完 CME 295 再上 CS329Z，你会对 RAG、Function Calling 这些概念有更好的理解基础。

**配套项目建议**：学 CS329Z 的同时，自己做一个完整的 Agent 项目。可以是一个“企业知识库问答 Agent”或“简历筛选工作流”。要求：**FastAPI 后端 + 真实数据 + 部署到云服务器 + 记录成本和延迟指标**。这是求职时最有力的作品。

## 第四阶段：CS336 原理补给（穿插/按需）

CS336 不是这条路线的主课，它是你的“原理词典”。课程目标是“从零手写语言模型”，内容极其底层：

- 手写 BPE 分词器、Transformer 架构、AdamW 优化器
- Triton 实现 FlashAttention、DDP 分布式训练
- Scaling Law、数据工程、SFT/RLHF/DPO 对齐

对你来说，**不需要系统学完，也不需要做作业**。正确用法是：当 CME 295 或 CS329Z 里遇到“这个东西底层到底怎么实现的”时，去 CS336 对应的讲义或视频里查。比如：

- 学 RAG 的 Embedding 时，好奇 BPE 怎么工作 → 看 CS336 Lecture 1-2
- 学 LoRA 时，想理解微调的底层机制 → 看 CS336 对齐部分的讲义
- 听到“Flash Attention”觉得很酷 → 看 CS336 的 Triton 实现（但不用自己写）

CS336 的 B站中英字幕版已经完整搬运，17 讲视频按需查阅即可。

## 为什么跳过 CS231n 和 CS230？

**CS231n（计算机视觉）**：主修方向是文本 Agent，除非未来涉及多模态图像理解，否则优先级很低。它的作业对 numpy 编程要求高，投入产出比不如直接学 CME 295。

**CS230（深度学习）**：吴恩达的深度学习基础课，偏“从零学神经网络”。你已经通过 CME 295 覆盖了 LLM 场景下的深度学习概念，不需要再从 CNN/RNN 时代重新走一遍。

## 一句话总结

**CME 295 建认知 → CS329Z 学工程 → 自己做项目 → CS336 查原理。** 这条路线直接对标 AI Agent 工程师岗位的核心能力栈，比“什么都学一点”的效率高得多。
